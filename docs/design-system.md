# EXVENTURE UI 기준 · v3

2026-10-02 · 홈페이지 / 통합 계정 / 업무 플랫폼

## 브랜드와 공통 파일

- 2026-10-02 사용자가 승인한 산업 이미지·차콜 탐색 메뉴·흰색 업무 영역·오렌지 곡선 X 로고를 기준으로 한다.
- `public/brand/exventure-orange-light.svg`와 `exventure-orange-dark.svg`는 교차하는 곡선 리본 X와 소문자 `exventure` 워드마크다. 글자는 경로로 저장해 외부 폰트나 기기별 글꼴에 의존하지 않는다. 어두운 메뉴에서는 `Brand tone="dark"`를 사용한다. 이전 공식 PNG 원본은 보존한다.
- 브라우저 아이콘도 같은 곡선 X를 사용한다. 로고 리본에는 `#ff8a24`에서 `#f05a13`로 이어지는 오렌지 그라데이션을 허용한다.
- 주요 색: 흰색 업무 영역, 차콜 `#171c21`, 탐색 메뉴 `#11171c`, 연한 회색 `#f5f6f7`, 시그니처 오렌지 `#f56718`. 작은 오렌지 글자는 대비를 확보하는 `#b43c06`, 어두운 메뉴의 선택 글자는 `#ff914e`를 사용한다.
- 주요 버튼은 시그니처 오렌지 바탕과 차콜 글자를 사용해 작은 글자의 대비를 확보한다. 성공·오류·진행 등 상태색과 의미는 유지한다.
- 작업 영역은 얇은 회색 선과 6~8px 모서리로 구분한다. 산업 이미지는 탐색 메뉴의 하단과 사선으로 잘린 배너에 제한해 문서 가독성을 유지한다.
- `public/brand/exventure-industrial-v1.png`는 내장 image_gen으로 생성한 산업 콘셉트 이미지다. 실제 엑스벤처 시설이나 고객 성과를 나타내는 사진으로 설명하지 않는다. 생성 명세는 `docs/brand-imagery.md`에 둔다.
- 기업 상세는 탐색 메뉴, 검색 가능한 기업 목록, 진단·IPA·분기·이력 영역, 업무 도우미로 구성한다. 도우미는 기존 기록의 완료·미입력 현황을 계산하고 실제 이슈 편집과 필터로 연결한다. AI 결과나 새 세션·승인 단계를 만들어 표시하지 않는다.
- 홈페이지 산출물 표현은 구성 예시로 표시하며, 고객·성과·통계를 만들지 않는다. 업무 홈은 회사 계정에 허용된 업무만 보여주며 실제 최근 업무·성과·권한을 추정해 표시하지 않는다.
- 시스템 한글 글꼴을 사용하며 외부 글꼴 요청을 필수로 두지 않는다.
- `src/components/brand.tsx`, `src/styles/exventure.css`, `src/app/icon.svg`, 새 SVG 로고와 산업 이미지는 세 저장소에서 같은 버전을 유지한다. 한 저장소에서 수정하면 나머지 두 저장소에도 동기화하고 SHA-256 일치를 확인한다. 업무 플랫폼 `/roadmap`의 아이콘도 동일하게 유지한다.
- 각 서비스는 독립 배포를 유지한다. 공통 파일 때문에 별도 런타임 서비스나 패키지 배포에 의존하지 않는다.
- 이전 업무 CSS는 `@layer legacy`로 분리한다. 공통 화면 규칙이 하위 경로의 CSS 로딩 순서에 영향을 받지 않도록 한다.
- 공통 규칙은 `@media screen` 안에 둔다. 보고서·인쇄 출력의 서식과 데이터 렌더러는 별도 소유 영역이다.

## 화면과 조작 기준

- 본문 15px, 입력창 16px, 보조 정보는 원칙적으로 13px 이상을 사용한다. 브랜드의 영문 보조 문구는 12px를 허용한다.
- 주요 버튼과 입력창 높이는 44~46px 이상. 아이콘 버튼은 접근 가능한 이름을 제공한다.
- 입력창의 경계, 선택된 메뉴, 오류·완료·미저장 상태를 글자와 형태로 함께 표시한다.
- 메뉴는 현재 위치를 `aria-current`로 알려준다. 모바일 탐색은 펼침 상태, 제어 대상, Esc 닫기와 초점 복귀를 제공한다.
- 탭은 방향키·Home·End, 선택된 탭 하나의 Tab 정지점, 연결된 패널 이름을 제공한다.
- 본문 바로가기, 눈에 띄는 키보드 초점, 동작 줄이기와 강제 색상 모드를 지원한다.
- 회사 계정·접근 권한·저장/출력의 의미는 화면 개편으로 바꾸지 않는다.

## 검증 범위

- 세 저장소의 기존 check 명령을 실행한다.
- 320px, 390px, 1440px에서 주요 공개 화면과 업무 컴포넌트의 가로 넘침 및 접근성 자동 검사를 수행한다.
- 로그인 오류/안내, 비밀번호 표시, 권한 일괄 선택과 저장 상태, 탐색 접기/검색, 탭과 대화상자의 키보드 조작을 확인한다.
- 인증이 필요한 화면은 실제 컴포넌트 + 가상 데이터 + 모의 서버 동작으로 격리해 검증한다. 운영 DB와 실제 계정 권한을 검증용으로 변경하지 않는다.
- 자동 검사 통과가 전체 WCAG 적합성 인증이나 실제 계정의 운영 SSO 검증을 뜻하지 않는다.
- 운영 반영은 각 변경 PR의 검사·검토와 배포 절차에 따른다.
