# 공개 문의 및 창업지원 도구

문의 페이지는 운영 서버 접수가 준비되지 않은 경우 회사 이메일로 이어지는 초안 작성 화면을 제공한다. 문의 종류·제목·내용으로 초안을 만들고, 복사하거나 메일 앱을 열어 사용자가 전송한다. 긴 한글 본문은 메일 앱의 URL 길이 제한에 대비해 제목만 연결하고 본문 복사를 안내한다. 웹사이트가 접수번호를 발급하거나 메일 전송 성공을 표시하지 않는다.

창업지원 도구는 사업계획 정리와 시장조사 설계의 네 가지 질문에 작성한 내용을 문서로 구성한다. 결과 복사와 UTF-8 텍스트 파일 내려받기를 지원한다. 두 도구의 입력 상태를 구분하며 입력을 바꾸면 이전 결과를 다시 생성하도록 한다. AI 생성 결과나 시장조사를 대신 수행한 결과로 표시하지 않는다.

새 도구의 입력은 브라우저 메모리에서 처리하며 서버 요청, localStorage, 외부 AI 호출을 추가하지 않는다. 페이지 이동 전에 결과를 보관하도록 안내한다. 기존 문의 API, 동의, 개인정보 설정, 관리자 권한 및 보존 제어는 유지한다. 운영 서버 문의 활성화 절차는 `inquiry-operations.md`를 따른다.

검증: Node.js 24의 `npm run check`에서 101개 테스트, 타입 검사 및 운영 빌드 통과. 브라우저에서 두 문서 생성, 복사, 텍스트 내려받기, 이메일 초안과 수신 주소 연결을 확인했다. 실제 메일 전송 및 운영 문의 저장은 실행하지 않았다. 320px·390px·1440px의 주요 화면에서 가로 넘침을 확인했다.
