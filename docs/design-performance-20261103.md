# 반응형 화면과 내부 이동 개선

현재 사진 중심 구성과 오렌지·차콜 브랜드를 유지한다. 내부 링크는 Next Link로 이동하여 전체 문서 재로딩을 줄이고, 주 내비게이션은 포커스/마우스 접근 시 미리 가져오기와 이동 상태를 제공한다. 해시 이동·연혁 검색 상태·목록 복귀를 유지한다.

빈 화살표 링크 2개에 목적을 설명하는 문구를 넣고 로그인·문의 전송·일반 링크의 반복되는 장식 화살표도 정리했다. 본문 링크는 밑줄과 포커스로, 관련 활동은 `기록 보기`, 계정 입구는 `직원 로그인`으로 목적을 드러낸다. 작은 화면의 본문 탐색, 제목/보조 정보 대비, 버튼 터치 영역, 메뉴 전환을 정리했다. 모션 줄이기를 지원한다. 기존 Pretendard subset 파일에는 장기 캐시 헤더를 적용했다. 문의 전송·계정 연동 로직은 변경하지 않는다.

검증: `npm run check`의 테스트 97개, 타입 검사와 운영 빌드 통과. 홈페이지·활동·소개 페이지를 320/390/768/1024/1440px에서 확인했으며 가로 넘침과 axe WCAG A/AA 위반은 없었다. 버튼 정리 후 홈페이지·활동·문의 화면은 1180px를 포함한 6개 폭에서 다시 확인했다. 내부 이동 시 문서 상태 유지, 해시 이동과 뒤로 가기를 브라우저로 확인했다.
